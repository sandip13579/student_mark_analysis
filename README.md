 Student Marks Analysis 📊

A beginner-friendly Data Science project built using **Python and NumPy** to analyze student marks and practice fundamental NumPy concepts.

 🚀 Project Overview

This project analyzes student marks using NumPy array operations and performs basic statistical analysis to understand student performance.

 🛠️ Technologies Used

* Python
* NumPy
* Jupyter Notebook

 📌 Concepts Practiced

* NumPy arrays
* Array operations
* Indexing and slicing
* Filtering data
* Mathematical operations
* Statistical calculations
* Working with numerical data

 🎯 Purpose

This project was created as part of my journey into **Data Science and Applied AI**. It helped me apply the NumPy concepts I learned to a practical dataset instead of only following tutorials.

 ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/sandip13579/student-mark-analysis.git
```

Open the project:

```bash
cd student-mark-analysis
```

Install NumPy if needed:

```bash
pip install numpy
```

Then open `student_marks_analysis.ipynb` using Jupyter Notebook or VS Code.
